# SisCompras Hambre Cero

Aplicación web estática para gestión de compras, instituciones, productos, inventario, recetas, menú semanal y órdenes de compra.

## Publicación

Este repositorio está pensado para conectarse a Vercel.

Configuración en Vercel:
- Framework Preset: Other
- Build Command: vacío
- Output Directory: vacío o `.`
- Install Command: vacío

## Datos

Los datos operativos deben guardarse en Supabase o importarse/exportarse desde la sección Datos de la app.
